## Untitled UI React

The four components in `src/components/ui/` are adapted from the free, MIT-licensed Untitled UI React source: https://github.com/untitleduico/react . Source files: `components/base/buttons/button.tsx`, `components/base/buttons/button-utility.tsx`, `components/base/textarea/textarea.tsx`, and `components/base/checkbox/checkbox.tsx`, retrieved on 12 October 2026.

Adaptations use the existing site's CSS tokens instead of Tailwind, retain React Aria interaction/accessibility primitives, expose the variants used by this chatbot, and omit the optional tooltip wrapper.
